Pages are Astro files in `src/pages/`. Each one is built from parts: a hero, a grid of features, a call to action and more.

## Add a page

- Create a file such as `src/pages/team.astro`.
- Import the parts you need from `@astronomic/ui`.
- Place them inside the site layout and save.

## Add a text page

For a plain text page, add a Markdown file to `content/pages/` instead. Its file name becomes its address, so `faq.md` shows at `/faq`.

A preset is a set of design tokens: fonts, colors, corner radius and spacing. Pick one, and every page follows it.

## Why a preset first

It is faster to choose a look than to build one. Start with a preset, ship the site, then adjust the few tokens you care about.

## What a preset changes

- Fonts for headings and body text
- Colors for text, surfaces and accents
- Corner radius and border width

The page code stays the same. Only the look changes.
